Cómo conectar Google Sheets
1. Abre tu Google Sheet → Extensiones → Apps Script
2. Borra el código existente y pega el siguiente:

function doPost(e) { var data = JSON.parse(e.postData.contents); var ss = SpreadsheetApp.getActiveSpreadsheet(); var sheet = ss.getSheetByName(data.sheet) || ss.insertSheet(data.sheet); if (sheet.getLastRow() === 0) { sheet.appendRow([ 'Fecha','Hora','Monto','Moneda', 'Categoría','Pago','Tipo', 'Facturado','Nota' ]); } sheet.appendRow([ data.fecha, data.hora, data.monto, data.moneda, data.categoria, data.pago, data.tipo, data.facturado, data.nota ]); return ContentService .createTextOutput(JSON.stringify({ok:true})) .setMimeType(ContentService.MimeType.JSON); }

3. Guarda (Ctrl+S)
4. Implementar → Nueva implementación → Aplicación web
5. Ejecutar como: Yo | Quién accede: Cualquier usuario
6. Copia la URL y pégala arriba ↑
